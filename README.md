# Kernel Core v0.2

This kernel does NOT generate answers.  
It prevents incorrect answers from being produced.

## What this is

Kernel Core is a structural enforcement layer for judgment systems.

It ensures:
- no hallucination
- uncertainty preservation
- evidence-based interpretation
- traceable reasoning

## What this is NOT

- not a model
- not a decision maker
- not a policy engine

It only prevents invalid judgment structures.
